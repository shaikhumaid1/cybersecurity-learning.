## Documentation standard

Each practical will record:
- Objective and investigation context
- Tool purpose, capabilities and limitations
- Methodology and procedure
- Lab environment and evidence source (where applicable)
- Actual observations and results
- Screenshots with sensitive information redacted
- Conclusion and references

**Evidence handling:** Original evidence should be preserved. Work on authorized test media or forensic copies, maintain acquisition records, and document errors or limitations. Do not publish private data, credentials, complete forensic images or unnecessary device identifiers.
